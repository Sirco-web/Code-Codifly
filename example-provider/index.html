📋 About This Provider

This is an example provider demonstrating how to create a provider site for Code Compiler. It hosts games and content that can be loaded dynamically.

Provider Type: HTTP Server (Node.js or Python)

Status: ✓ Online and running

⚠️ IMPORTANT: Code Format

All codes must be exactly 4 alphanumeric characters (letters and/or digits)

  • ✅ Valid: snk1, test, 2048, pong
  • ❌ Invalid: abc (too short), abcde (too long), abc! (special char)

🎮 Available Games (4-Char Codes)

🚀 How to Use This Provider

Step 1: Register this provider in Code Compiler console:

/register-url add games http://localhost:3000/?code=

Step 2: Load a game using a 4-character code:

/load-code snk1
/load-code 2048
/load-code pong

Step 3: See provider info:

/reg-url list

📁 Provider Structure

example-provider/
├── codifly.json          # MANDATORY metadata (required!)
├── index.html            # This page
├── server.js             # Node.js implementation
├── server.py             # Python implementation
└── games/                # (Optional) Game files

💡 Starting a Server

Node.js:

cd example-provider
node server.js

Python:

cd example-provider
python3 server.py

Static (Python):

cd example-provider
python3 -m http.server 3000
