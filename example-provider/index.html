📋 About This Provider

This is a STATIC provider - no servers needed! Just HTML files and a codifly.json metadata file.

How It Works:

  • codifly.json defines the available codes (snk1, gm48, pong)
  • Each code maps to a static HTML file
  • Code Compiler loads the HTML and caches it
  • Provider is served as-is (no server processing needed)

⚠️ IMPORTANT: Code Format

All codes must be exactly 4 alphanumeric characters (letters and/or digits)

  • ✅ Valid: snk1, test, 2048, pong
  • ❌ Invalid: abc (too short), abcde (too long), abc! (special char)

🎮 Available Games (4-Char Codes)

💾 Cache & Assets Information

What gets cached? Complete game HTML with inline CSS and JavaScript

Per Game:

snk1:  Complete Snake game (HTML, JavaScript, CSS)
2048:  Complete 2048 game (HTML, JavaScript, CSS)
pong:  Complete Pong game (HTML, JavaScript, CSS)

Storage: Code Compiler automatically caches each game's HTML response

Benefit: Games load instantly on subsequent visits, even offline

🚀 How to Use This Provider

Step 1: Register this provider in Code Compiler console:

/register-url add games http://localhost:3000/

Step 2: Load a game using one of the defined 4-character codes:

/load-code snk1
/load-code gm48
/load-code pong

Step 3: See provider info:

/reg-url list

💡 Serving This Static Provider

Use ANY static file server:

Python (Built-in):

cd example-provider
python3 -m http.server 3000

Node.js (http-server):

cd example-provider
npx http-server -p 3000

VS Code (Live Server):

Right-click index.html → Open with Live Server
